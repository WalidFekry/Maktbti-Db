# Maktbti Database Repository

This repository contains the database files (`quran.db`) used in the Maktbti Quran Android application.

## Purpose

- Centralized storage for the Quran database files.
- Easy to update and maintain the database files independently from the app source code.
- Provide reliable download URLs for the app fallback mechanism.

## Files

- `quran.db`: The main Quran database file used by the app.

## How to update

1. Replace the existing `quran.db` file with the updated database.
2. Create a new GitHub Release with the updated `quran.db` as a release asset.
3. Update the app's fallback URL if the release version changes.

## Download URLs

Use the GitHub Releases download URL for stable, public access to the database file.  
Example:  
`https://github.com/WalidFekry/Maktbti-Db/releases/download/v1.0/quran.db`
